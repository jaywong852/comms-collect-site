# 通訊稿收集網站

親切易填嘅公開網站：先揀通訊期，再交通訊稿；交完可以去**活動一覽**整理排列，同埋睇**日誌表**（每月活動一覽）。

呢個係靜態網站，交稿資料讀寫已準備好嘅 Supabase 專案（`public.submissions`）。前端設定喺 `src/config.js`，用嘅係可以放喺瀏覽器嘅 publishable key。唔好把 service role、密碼，或者交稿資料檔提交上嚟。

交稿（主頁、新增活動、匯入以往活動）公開，唔使登入。日誌表可以公開瀏覽。**活動一覽**嘅編輯、排序、刪除，以及兩個 Word **匯出**，都要先登入後台帳號。日誌表頁面本身公開，只有「匯出」要登入；未登入就會打開登入／設定帳號，完成後再試一次。

## 使用流程

1. 首頁 → 揀通訊期（顯示五期；4 月至翌年 3 月為一個年度，較新年度在上）
2. **新增活動**（公開；可匯入以往活動）
3. **活動一覽**（要登入先可以拖曳排序、編輯、刪除同匯出。一入去只顯示編輯同排序，要先撳「刪除」先進入刪除模式。拖曳排序會同步活動編號為 1、2、3…；可刪單一活動或勾選後批次刪除，刪後會重新編號）
4. **日誌表**（公開可睇；三個月格，格內顯示編號＋名稱＋時間。匯出 Word 要先登入）
5. **後台**（同活動一覽用同一個後台帳號）

用詞用「匯出／匯入」。

## 後台帳號

- 未有管理員時，打開活動一覽、後台，或者未登入就撳匯出，會見到「設定後台帳號」。要填電郵、密碼、確認密碼。密碼最少 8 個字。
- 第一個成功註冊嘅帳號會成為管理員。之後再註冊會被拒絕。
- 已經有管理員就顯示登入（電郵同密碼）。如果呢個瀏覽器未知有冇帳號，設定頁下面有「已有後台帳號？登入」。
- 登入或者註冊成功之後，程式會 `refreshSession()`；如果 JWT 仲未有管理員身份，會再登入一次。
- 活動一覽同後台工具列有登出。
- 網站唔會提供預設密碼，亦唔會把密碼寫入程式、註解或者呢份說明。
- 如果 Supabase 開咗「Confirm email」，設定帳號之後要先到電郵按確認連結（請用同一個瀏覽器打開），再用同一組電郵同密碼登入。想設定完即刻入到後台，可以喺 Supabase Auth 關掉電郵確認。呢個網站冇改呢個設定。
- 請喺 Supabase Auth 的 URL Configuration 允許呢兩個網址，電郵確認先返到呢個站：
  - `http://localhost:5173/comms-collect-site/`
  - `https://jaywong852.github.io/comms-collect-site/`

## 通訊期編碼

內部編碼仍為 `YYYY-QN`（網址用）：Q1=1–3月、Q2=4–6月、Q3=7–9月、Q4=10–12月。  
畫面上顯示為期號，由 2027 年第 1 季＝第 65 期起計：

- `2027-Q1` → 第65期（2027年1–3月）
- `2027-Q2` → 第66期（2027年4–6月）
- `2027-Q3` → 第67期（2027年7–9月）
- `2027-Q4` → 第68期（2027年10–12月）
- `2028-Q1` → 第69期（2028年1–3月）

首頁顯示：第65期至第69期（五期）。2027–2028年度（第66–69期）在上，第65期屬 2026–2027年度，放喺下面。

整理頁按系列分組，只可喺同一系列內拖曳；儲存後會重新編全球編號 1…n。

## 活動編號

- 編號**永遠等於**「系列優先 + 組內 `sort_order`」之後嘅位置（1、2、3…）
- 資料庫冇獨立編號欄。拖曳改次序會更新 `sort_order`；交稿唔可以人手改編號
- 公眾交稿唔可以自己指定次序；該期 `sort_order` 會由資料庫設成當時最大再加 1
- 日誌表同列表顯示呢個排序編號

## 日期解析（日誌表）

優先用 `date_list`（`YYYY-MM-DD` 陣列）。否則解析 `date` 文字，支援例如：

| 寫法 | 結果（以 2027 年期為例） |
|------|--------------------------|
| `2027年5月1日` | 2027-05-01 |
| `5月1日`／`4月5日(五)` | 該年該日 |
| `10月9、30日` | 兩日 |
| `10月9、30日；11月13、27日` | 四日 |
| `1月13、20、27及2月3日(星期三)` | 四日 |
| `2027-05-01` | ISO |

未能辨識或唔喺呢三個月內嘅活動，會列喺日誌表下方「未入日誌表」。

## 香港公眾假期（日誌表）

日誌表格內會標示香港公眾假期（粉紅色標示＋假期名稱）。假期資料存於 `lib/hk-holidays.js`：

- **2027**：按政府已刊憲名單（GovHK）
- **2028**：暫按常規／農曆推算（刊憲前為暫定；刊憲後應更新檔案）

## 本機開發

```bash
npm install
npm run dev
```

打開 http://localhost:5173/comms-collect-site/

```bash
npm test
npm run build
npm run preview
```

`npm run build` 會產出 `dist/`，base path 係 `/comms-collect-site/`。Word 匯出喺瀏覽器完成，唔使再行 Express。

## 資料

交稿存在 Supabase `public.submissions`（snake_case）。時間同地點、集合時間同集合地點喺表單並排。網站唔會再把交稿寫入本機資料檔。

## GitHub Pages

Push 去 `main` 會行 `.github/workflows/pages.yml`：測試、建置，再用 GitHub Actions 部署 Pages。Repo 設定要揀 GitHub Pages 來源為 GitHub Actions。呢個 workflow 唔會把 repo 改成 public。
