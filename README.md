# 通訊稿收集網站

親切易填嘅公開網站：先揀通訊期，再交通訊稿；交完可以去**活動一覽**整理排列，同埋睇**日誌表**（每月活動一覽）。

交稿（主頁、`/submit`、導入以往活動）公開，唔使登入。日誌表可以公開瀏覽。**活動一覽**嘅編輯、排序、刪除，以及兩頁嘅 Word **匯出**，都要先用後台密碼登入。第一次開啟活動一覽或後台時，如果未設定密碼，可以即場設定；網站冇預設密碼。

## 使用流程

1. 首頁 `/` → 揀通訊期（顯示五期）
2. **交通訊稿** `/submit?period=2027-Q2`（公開；可導入以往活動）
3. **活動一覽** `/manage?period=2027-Q2`（要登入先可以拖曳排序、編輯、刪除同匯出。拖曳排序會同步活動編號為 1、2、3…；可刪單一活動或勾選後批次刪除，刪後會重新編號）
4. **日誌表** `/calendar?period=2027-Q2`（公開可睇；三個月格，格內顯示編號＋名稱＋時間。匯出 Word 要先登入）
5. **後台** `/admin`（同活動一覽用同一組後台密碼；第一次訪問可設定密碼）

## 後台密碼

- 未設定時，打開活動一覽或 `/admin` 會見到「設定後台密碼」。密碼最少 8 個字元，輸入兩次確認之後會儲存並自動登入。
- 密碼會以雜湊存喺 `data/admin-auth.json`（唔會明文保存，呢個檔已列入 `.gitignore`）。
- 之後用「後台登入」輸入同一組密碼，就可以整理活動同匯出。
- 可用環境變數 `ADMIN_PASSWORD` 作為托管時嘅可選覆寫：如果未有雜湊檔，登入會核對呢個環境變數；若已有雜湊檔，會優先核對檔案。
- 網站唔會提供預設密碼，請自己設定並妥善保管。

## 通訊期編碼

內部編碼仍為 `YYYY-QN`（API／網址用）：Q1=1–3月、Q2=4–6月、Q3=7–9月、Q4=10–12月。  
畫面上顯示為期號，由 2027 年第 1 季＝第 65 期起計：

- `2027-Q1` → 第65期（2027年1–3月）
- `2027-Q2` → 第66期（2027年4–6月）
- `2027-Q3` → 第67期（2027年7–9月）
- `2027-Q4` → 第68期（2027年10–12月）
- `2028-Q1` → 第69期（2028年1–3月）

首頁顯示：第65期至第69期（五期）。

整理頁按系列分組，只可喺同一系列內拖曳；儲存後會重新編全球編號 1…n。

## 活動編號

- `number` **永遠等於**「系列優先 + 組內次序」後嘅位置：`sortOrder + 1`（1、2、3…）
- 拖曳改次序即更新編號；交稿／編輯唔可以人手改編號
- 日誌表同列表顯示呢個排序編號

## 日期解析（日誌表）

優先用 `dateList`（`YYYY-MM-DD` 陣列）。否則解析 `date` 文字，支援例如：

| 寫法 | 結果（以 2027 年期為例） |
|------|--------------------------|
| `2027年5月1日` | 2027-05-01 |
| `5月1日`／`4月5日(五)` | 該年該日 |
| `10月9、30日` | 兩日 |
| `10月9、30日；11月13、27日` | 四日 |
| `2027-05-01` | ISO |

未能辨識或唔喺呢三個月內嘅活動，會列喺日誌表下方「未入日誌表」。


## 香港公眾假期（日誌表）

日誌表格內會標示香港公眾假期（粉紅色標示＋假期名稱）。假期資料存於 `lib/hk-holidays.js`：

- **2027**：按政府已刊憲名單（GovHK）
- **2028**：暫按常規／農曆推算（刊憲前為暫定；刊憲後應更新檔案）

## 本機啟動

```bash
cd comms-collect-site
npm install
npm start
```

- http://localhost:3000/
- 環境變數：
  - `PORT`（預設 3000）
  - `ADMIN_PASSWORD`（可選覆寫；見「後台密碼」）
  - `SESSION_SECRET`（可選；未設定時會喺 `data/session-secret` 自行產生並保存，呢個檔已列入 `.gitignore`）
  - `COOKIE_SECURE=1` 或 `NODE_ENV=production`：Cookie 設為 `secure`，並啟用 `trust proxy`，方便日後以 HTTPS 托管

## 資料

`data/submissions.json`：含 `period`、`sortOrder`、`number`、`date`、`time`、`location`、可選 `assemblyTime`／`assemblyPlace`（集合時間／集合地點）、可選 `dateList` 等。舊資料啟動時會自動補 `number`／`dateList`／集合欄。

## 公開部署

Render／Railway 等；請確保 `data/` 可寫入（用來保存提交、後台密碼雜湊同 session secret）。交稿頁同日誌表瀏覽公開；活動一覽管理同 Word 匯出需後台密碼。若用 HTTPS，建議設定 `COOKIE_SECURE=1` 或 `NODE_ENV=production`。亦可改用 `ADMIN_PASSWORD` 同 `SESSION_SECRET` 環境變數，而唔依賴本機檔案。
